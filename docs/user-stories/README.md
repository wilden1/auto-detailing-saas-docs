## Adding a story

1. Take the next free `US-###`.
2. Copy [`templates/user-story-template.md`](../../templates/user-story-template.md).
3. Name its parent feature; list the `BR-###` and `NFR-###` it depends on.
4. Check it against the [Definition of Ready](../agile/definition-of-ready.md) before
   marking it `READY` — in particular, that no open question blocks it.
5. Add a row here and to the parent feature in the same change.
