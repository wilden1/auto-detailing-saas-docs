## Adding a feature

1. Take the next free `FEAT-###`.
2. Copy [`templates/feature-template.md`](../../templates/feature-template.md) to `FEAT-###-slug.md`.
3. Name its parent epic; add it to the parent epic's feature table.
4. Add a row here in the same change.
